# 够级 - 六人联网对战

山东扑克够级的在线多人版本，6人实时对战。

## 快速开始

安装依赖后执行 `npm start`，浏览器打开 `http://localhost:3000`；同一局域网的朋友使用服务器输出的局域网地址。
执行 `npm test` 运行规则回归测试。

## 玩法

1. 一人创建房间，得到4位房间号
2. 把房间号发给朋友
3. 朋友打开同一个网址，输入房间号加入
4. 6人到齐，房主点"开始游戏"

## 适合我们的赖皮机制


允许偷牌孬急等

## 本桌规则与连续对局

- 每人开局54张牌，其中恰好一张3；进贡、还贡和幸运发牌不会转移这张3。
- 2可补普通牌的张数：五张5加一张2按六张5计算；带2的牌不能用于纯够级开点。
- 纯特殊牌逐张比较，每张都必须更大：小王加2不能压两个2；两个大王可压一个大王。
- 烧牌必须带王，续烧每手至少带一张王，最后一手纯3除外；续烧不必压过自己上一手。
- 普通出牌每回合20秒；还贡、买4阶段各12秒。选牌或其他玩家使用技能不会重置当前出牌时间。
- 一个团伙退出后立即结算。已出完者保留顺序，其余玩家按剩余牌数从少到多排名，牌数相同按座位号排序；烧失败者按原规则放在末尾。
- 创建房间默认五局连打，房主可在等待房改为一直连打；结算后5秒自动开下一局，五局模式完成第5局后停止。下一局保留进贡和装备结算。
- 其他玩家手牌张数默认隐藏。
